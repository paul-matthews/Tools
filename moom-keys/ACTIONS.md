## Binding them in Alfred

Each script needs one Alfred hotkey, once. In a workflow, add a **Hotkey** trigger, record the chord, and connect it to a **Run Script** action set to `/usr/bin/osascript` with the script's path. Alfred's Powerpack is required for workflows.
