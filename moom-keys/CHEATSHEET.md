## Keyboard layer

Each key on the window layer sends its region's Hyper chord. In Keychron Launcher these go in as custom (`Any`) keycodes:

| Key | QMK keycode |
| --- | --- |
| `Space` | `HYPR(KC_SPC)` |
| `H` | `HYPR(KC_H)` |
| `J` | `HYPR(KC_J)` |
| `K` | `HYPR(KC_K)` |
| `L` | `HYPR(KC_L)` |
| `;` | `HYPR(KC_SCLN)` |
| `G` | `HYPR(KC_G)` |
| `'` | `HYPR(KC_QUOT)` |
| `7` | `HYPR(KC_7)` |
| `8` | `HYPR(KC_8)` |
| `0` | `HYPR(KC_0)` |
| `Y` | `HYPR(KC_Y)` |
| `U` | `HYPR(KC_U)` |
| `I` | `HYPR(KC_I)` |
| `O` | `HYPR(KC_O)` |
| `P` | `HYPR(KC_P)` |
| `N` | `HYPR(KC_N)` |
| `M` | `HYPR(KC_M)` |
| `,` | `HYPR(KC_COMM)` |
| `.` | `HYPR(KC_DOT)` |
| `/` | `HYPR(KC_SLSH)` |

Caps Lock is `LT(<window layer>, KC_ESC)`: held it selects the layer, tapped it is still Escape. Keys with no region are transparent, so they type normally.

## Scripting

Every region is addressable by title once Moom's AppleScript support is enabled:

```applescript
tell application "Moom" to run "Camera stage"
```
